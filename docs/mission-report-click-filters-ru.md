# Отчёт по миссии `ahawr-dashboard-click-filters`

Коммит `4f31f58`, развёрнут в `ahawr-dashboard` 15.10.2026. Проверки ниже повторены 15.10 на Linux в контейнере агента; это не вывод задачи T014, оригинальные выводы T014 в журнале не сохранились.

## Что получилось

- Каждое значение в заголовке прогона (статус, источник, роль, model, provider, session, cwd) и роль, model, provider в строке списка кликабельно. Клик ставит значение в общий фильтр, повторный клик убирает его. Клик в списке прогон не выбирает.
- Разные поля объединяются по И, значения одного поля по ИЛИ. Подсказка на странице (`dashboard.html:224`): «Fields are combined with AND; values of one field are combined with OR».
- Активный фильтр показан плашками. Выпадающие списки источника, роли и статуса из левой колонки удалены. Фильтр хранится в адресе страницы.
- `GET /api/runs` принимает model, provider, cwd и несколько значений одного поля (повторяющиеся параметры). `limit` считается после фильтра. Прогоны Hermes имеют `provider="hermes"` и `cwd=""`, поэтому при несовпадении фильтра они скрываются (`README.md:275`).
- Полнотекстовый поиск (`GET /api/search`, `README.md:278`) ищет по журналам всех прогонов без учёта регистра. Минимальная длина запроса 2 символа, до 5 совпадений на прогон. Пределы: 2000 просканированных прогонов, 3 секунды, максимум 200 результатов. Если поиск остановился раньше, ответ помечен `incomplete`. Теги фильтра сужают поиск.
